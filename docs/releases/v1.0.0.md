# AAJ Contact Scan v1.0.0

AAJ Contact Scan V1 is the first production release of the event business-card workflow tested on real mobile devices.

## Highlights

- Capture or select cards on an Android phone.
- Extract through an automatic Gemini model pool with Workers AI fallback.
- Review and correct every contact before approval.
- Download or share a HubSpot-ready CSV.
- Back up approved contact text, never card photographs.
- Recover an event CSV using a separate administrator session.
- View team-wide privacy-safe AI capacity information.

## Public repository

The repository is intentionally public and includes an MIT code licence, twelve synthetic demonstration cards, a GIF captured from the real production interface and isolated-deployment instructions. Production keys and passcodes remain Cloudflare secrets and are not present in Git history.

## Upgrade and deployment

Before deploying a fork, create independent usage and backup D1 databases, replace both database IDs, apply the matching migrations and create new `GEMINI_API_KEY`, `TEAM_PASSCODE` and `BACKUP_ADMIN_PASSCODE` secrets. Do not connect a fork to AAJ production resources.

Existing AAJ installations should pull the tag, run `npm install`, `npm test` and `npm run build`, then deploy the Worker. The V1 deployment adds two Cloudflare rate-limit bindings with namespaces `1001` and `1002` in the AAJ account.

## Known boundaries

- Rate limiting is approximate per Cloudflare location rather than a strict global counter.
- Gemini remaining-capacity values are estimates based on configured account limits.
- The documented 180-day backup retention target is reviewed and enforced manually in V1.
